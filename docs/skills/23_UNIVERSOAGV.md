# Produto — UNIVERSO AGV

## Identificação

Cliente: Universo Agv. CLIENTE = UNIVERSO AGV.

## Assistência

Valor do campo "Protocolo".

## Categoria

- Reboque Utilitario → UTILITARIO
- Pane eletrica (observação) → SOCORRO MECANICO (se o Tipo de Serviço for genérico ou não indicar porte)

## Origem

Cidade do campo "Origem" dentro de "Endereço de Acionamento". Ex: Itau de Minas.

## Destino

Cidade do campo "Destino" dentro de "Endereço de Acionamento". Ex: Itau de Minas.

## KM TOTAL

Valor do campo "Percurso Total".

## VALOR

Valor do campo "Valor".

## Ignorar

Previsão, Solicitante, Telefone, Nome / Nome Fantasia, Veículo, Placa, Ano, Cor do Veículo, Combustivel, Observações (exceto para identificar origem/destino se não explícito), Viatura Próxima, Plano, perguntas do questionário (O veículo está em uma garagem ou subsolo?, É um local de fácil acesso?, Existe rodas estão travadas?, O veículo “dá partida”?, O veículo é rebaixado ou original de fábrica?, Na sua percepção o que provocou esta pane?).

## Observação

Se o "Tipo de Serviço" for "Reboque Utilitario" e a observação indicar "Pane eletrica", a categoria principal ainda é UTILITARIO, mas a observação pode ser considerada para contexto.
