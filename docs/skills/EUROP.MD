# Produto — EUROP

## Identificação

Cabeçalho EUROP ou Contratante: SEM PARAR INSTITUICAO DE PAGAMENTO LTDA. CLIENTE = EUROP.

## Assistência

Usar o valor do campo "# Serviço".

## Categoria

Classificar a partir do campo "Tipo de serviço":

- REBOQUE - LEVE → LEVE
- REBOQUE - UTILITÁRIO → UTILITARIO
- REBOQUE - PESADO → PESADO
- REBOQUE - EXTRA PESADO → EXTRA PESADO
- TAXI → TAXI
- CHAVEIRO → CHAVEIRO
- SOCORRO MECÂNICO / PANE MECANICA → SOCORRO MECANICO

## Origem e Destino

Usar os blocos numerados em "LOCAIS DO ATENDIMENTO":
- Endereço completo (1) → Extrair somente o campo "Cidade" para ORIGEM.
- Endereço completo (2) → Extrair somente o campo "Cidade" para DESTINO (se houver; caso contrário, deixar vazio).

## KM TOTAL

Não preencher. Deixar sempre vazio.

## VALOR

Não preencher. Deixar sempre vazio.

## Ignorar

Chassi, Marca, Modelo, Cor, Ano, Combustível, Segurador/Beneficiário, Solicitante, Telefones/Celular, Causa, Status, Estimativa, Previsão de chegada, Descrição, Veículo vinculado, Colaborador, GPS/Sinais e informações complementares de endereço.
