# Produto — BRADESCO

## Identificação

Contratante: BRADESCO AUTORE COMPANHIA DE SEGUROS. CLIENTE = BRADESCO.

## Assistência

Usar o valor do campo "# Serviço".

## Categoria

Usar "Tipo de serviço".

- REBOQUE - LEVE → LEVE
- REBOQUE - UTILITÁRIO → UTILITARIO
- REBOQUE - PESADO → PESADO
- TAXI → TAXI

## Origem e destino

Usar os "Endereços completos" numerados em LOCAIS DO ATENDIMENTO: (1) = ORIGEM, (2) = DESTINO. Extrair somente a cidade.

## KM

Não usar link de mapa. Usar apenas KM explícito e associado ao serviço.

## Valor

Preencher somente com valor total explícito.

## Ignorar

Chassi, Segurador/Beneficiário, Solicitante, Veículo, Placa, Colaborador (motorista), Status, Data de agendamento, Previsão de chegada.
