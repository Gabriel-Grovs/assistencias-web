# Produto — TATO ASSIST

## Identificação

TATO ASSIST, Protocolo iniciado por 202... CLIENTE = TATO ASSIST.

## Assistência

Valor do campo Protocolo.

## Categoria

- Reboque Leve → LEVE
- Reboque Utilitário → UTILITARIO
- Reboque Pesado → PESADO
- Reboque Extra Pesado → EXTRA PESADO
- Taxi → TAXI
- Chaveiro → CHAVEIRO
- Troca de pneu → TROCA PNEU
- Socorro mecânico → SOCORRO MECANICO

## Origem e destino

Cidade após Origem / Destino.

## KM

Prioridade: Percurso Total > KM total explícito > componentes de tarifa só se inequívocos. Não usar "Viatura Próxima".

## Valor

Usar campo Valor ou total das tarifas quando claramente associado.

## Regra especial

"Reboque Utilitário" → UTILITARIO, mesmo com observação de pane elétrica/mecânica.

## Ignorar

Nome do segurado, solicitante, telefone, placa, viatura, prestador, status, previsão.
